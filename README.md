# TACT Lifestyle storefront concept

A responsive, editorial storefront demo for TACT Lifestyle.

- Media is downloaded from TACT's own Shopify storefront and documented in `ASSET_SOURCES.md`.
- Product and collection links lead to the live TACT store.
- Search, menu, newsletter confirmation, concept bag, and responsive product/category layouts are interactive.

## Local development

```bash
pnpm install
pnpm dev
```

## Validation

```bash
pnpm typecheck
pnpm build
pnpm build:cloudflare
```
